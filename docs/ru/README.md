# SendTV: план и реализация

[English](../../README.md) · Русский

Локальный протокол и продукт для передачи ссылок с телефонов, планшетов, браузеров и компьютеров на телевизор. **V1 реализована для проверки разработки; это не проверенный публичный релиз.**

## Состояние
Нативный Kotlin-приёмник включает явный запуск/остановку, LAN-привязку, временный QR, подтверждение на ТВ, сохранение хешей и отзыв, аутентифицированную HTTP-передачу URL и статус, встроенный TypeScript-отправитель. Есть автоматические тесты безопасности, сокетов, Android ресурсов/intents, Chromium/WebKit. Контролируемые сценарии физического ТВ/браузера проверены; оставшаяся матрица сети/браузеров и публичный deploy сайта открыты. V2/V3 не начаты.

Приложение поддерживает **English и Русский**. Настройки ТВ позволяют выбрать язык системы или явный язык; отправитель учитывает язык браузера и имеет переключатель. Публичные страницы сайта имеют отдельные русские маршруты. Здесь находятся русские версии инженерных документов с сохранением английских оригиналов. Код, команды, API-поля и error codes не переводятся.

Сборка и оставшиеся задачи: [разработка V1](docs/development-v1.md). [Эталоны проверены через Pencil MCP](design/validation/README.md); реальные экраны и ограничения — в [протоколе V1](docs/verification-v1.md). Экспериментальную сборку нельзя публиковать как проверенный V1-релиз.

## Основные ограничения
- В V1 обязателен приёмник Android TV. **Нельзя обещать открытие любых URL на произвольном неизменённом ТВ.**
- QR ведёт к веб-интерфейсу с ТВ. Нативный discovery — позже.
- В обычном продукте нет аккаунтов, облака, ADB, отслеживания и навязчивого доступа.
- HTTP(S) URL открывается только после сопряжения и проверки прав. Не исполняйте удалённые команды оболочки.
- Имена, package ID, домены и владелец GitHub в исходном плане — предварительные до окончательного выбора.

## Последовательность
V1: URL → ТВ. V2: поиск, несколько устройств, CLI. V3: файлы и управление. V4+: другие ОС ТВ и необязательный кастинг.
