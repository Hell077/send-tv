# ADR 0002: начальная минимальная версия Android для V1

[English](../../../../architecture/decisions/0002-v1-android-floor.md)

Статус: принято для первоначальной совместимости V1.

## Решение
V1 рассчитана на Android TV/Google TV с Android 11 (API 30) и новее. В APK `minSdk = 30`, compile/target SDK остаётся 36. Framework/resource-тесты охватывают API 30 и 34.

## Доказательства
Приёмник установлен и работал на физическом MiTV-MOOQ1 с Android 11/API 30 и эмуляторе Android TV API 34. На физическом ТВ проверены LAN-сервер, разрешение на ТВ, HTTPS-передача установленному браузеру, сохранение доверия после перезапуска, отзыв одного устройства и D-pad с начальным фокусом на отказе. Ревизия и ограничения — в [протоколе проверки V1](../../docs/verification-v1.md).

## Компромисс
Исходный API 26 был предварительным. Поддержка ограничена самой старой реально проверенной ТВ-платформой, а не объявлена сертификацией Android 8–10. Старые ТВ можно оценить отдельным изменением совместимости и тестами. Это не гарантия для всех API 30+ моделей и сайтов: влияют производитель, обработчик, DRM, cookies и пульт.

APK с минимумом API 30 успешно переустановлен на физическом ТВ 2026-11-04; приёмник запустился и показал действующий QR. Это проверка разработки, а не подписанный релиз или сертификация.
