# Модель угроз и сопряжение

[English](../../../architecture/security.md)

## Угрозы
Злоумышленник в общем Wi-Fi; повтор nonce из QR; кража bearer-токена; запросы с постороннего сайта; поддельный приёмник; случайный URL с опасной схемой; перехват LAN-пакетов; изоляция гостевой сети; отказ в обслуживании и злоупотребление.

## Защита V1
1. ТВ показывает непредсказуемый одноразовый временный challenge; обновляет после использования или истечения.
2. Первое сопряжение явно подтверждается на ТВ: имя устройства и, где возможно, одноразовая проверочная фраза.
3. Endpoint сопряжения строго ограничен по частоте. Долгосрочный ограниченный токен никогда не входит в QR.
4. Для `open` нужен токен; на диске — хеши, отзыв по устройствам, замена при утечке.
5. Строгая политика `Origin` браузера, `SameSite` при использовании cookies, защита от CSRF и подходящий CORS; никакого wildcard CORS.
6. Только `http://` и `https://`; предел длины, например 4096 символов; запрет встроенных данных входа; предел тела. Не принимать `javascript:`, `file:`, `intent:`, `content:` и команды оболочки.
7. Предпочтительны HTTPS-адреса назначения, но HTTP поддерживается с явным описанием компромисса.
8. Ограничивайте запросы, соединения и таймауты; не записывайте URL с секретами в query по умолчанию.
9. Привязка к нужным LAN-интерфейсам, без UPnP-перенаправления и публичного сервера.
10. Понятное состояние владельцу и немедленный отзыв доступа у всех устройств.

## Ограничения безопасности
Локальный HTTP виден во враждебной сети. Нельзя обещать зашифрованный/защищённый транспорт до внедрения аутентифицированного TLS. Возможный подход для нативных клиентов — самоподписанный сертификат ТВ и закрепление отпечатка; браузеру нужна стратегия доверенных сертификатов. Обычный LAN HTTP не является secure origin.

## Проверка
- Неизвестный токен: 401; отозванный: 401; неверный Origin/CSRF: отказ; истёкший challenge: отказ.
- Неавторизованный `open` никогда не запускает Android Intent.
- QR нельзя использовать повторно после успешного сопряжения.
- Fuzz/некорректный JSON и URL в десять раз длиннее предела отклоняются безопасно.
- Обнаружение устройства не означает аутентификацию.
