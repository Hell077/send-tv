# Дизайн отправителя

[English](../../../../design/sender/app_design.md)

Источники: `app_design.pen`, мобильный экран и сопряжение/обратная связь; общая [дизайн-система](../design-system.md).

## Мобильный V1
390×844, заголовок SendTV, выбранный приёмник «ТВ в гостиной», статус «Подключено», URL-поле со вставкой, основная кнопка «Открыть на ТВ», краткое объяснение. Недавние ссылки отложены.

## Автомат состояний
`unpaired -> pairing-requested -> waiting-for-tv-confirmation -> paired -> sending -> launched | failed`. `launched` означает принятие передачи Android, а не загрузку страницы. На каждом шаге предусмотрены возврат/повтор; таймаут явный.

## Обязательные экраны
1. Подключение: QR deep-link, сведения о ТВ и предупреждение доверия.
2. Ожидание: загрузка, инструкция на ТВ, отмена.
3. Подключено: URL, вставка, выбранный ТВ, открытие.
4. Успех: «Отправлено на ТВ» / «Открыто ТВ-браузером» только после подтверждения запуска; возврат к вводу.
5. Ошибки: URL, недоступный ТВ, отозванный токен, отсутствие браузера.
6. Выбор устройства — только V2, с явным различением ID и имени.

## Взаимодействие и доступность
URL input mode, вставка; очистка только с явным объяснением, без молчаливой правки URL. Цели касания от 44 px. Ожидание запрещает повторную отправку, но позволяет отмену где возможно. Статусы объявляются скринридеру. Переключатель English/Русский не сбрасывает текущую операцию и пользовательский ввод.

## Настольный отправитель
Тот же UI шириной до 440 px по центру; расширяемый список устройств возможен в V2. Отдельного языка дизайна для desktop нет.
