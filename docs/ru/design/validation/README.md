# Проверка эталонов Pencil, 2026-11-04

[English](../../../../design/validation/README.md)

Изображения получены установленным MCP Pencil (`Pen.app`). Это **дизайн-эталоны**, не работающие SendTV или сайт. Они не доказывают точность реализации и совместимость устройств.

## Подключение и схема
Локальная конфигурация Codex включает `pencil`, встроенный `mcp-server-darwin-arm64` с `--app desktop --agent codexCLI`. Доступ через MCP stdio: инструменты не были напрямую выставлены в разговор. Разрешения computer use и конфигурация Codex не менялись.

`read_skill` и `pen-schema.md` объявляют версию `2.21`. Исходники имели `2.22`; `get_app_state` ТВ показывал пустой документ. Временная копия только с другой версией загрузила оба ТВ-фрейма. Все три исходника теперь `2.21`. Сравнение с Git подтвердило сохранение всех узлов, подписей, ID, цветов и координат.

`get_app_state`, `execute`/`Get`, `TakeScreenshot` проверили фреймы. Пустой кеш ТВ восстановлен через MCP из исходных редактируемых узлов. Отправитель и сайт загрузились после исправления заголовков. Превью имеют разрешение MCP, не полное разрешение приложения.

## Последующие проверки реализации
- В ТВ-эталоне обводка отказа 1 px; в приложении фокус от 3 px и начинается на отказе/нейтральном действии. Часть пояснений меньше специфицированных 28 px.
- В отправителе некоторые тексты 15 px; в runtime минимум 16 px. Нужны desktop, 320 px, ошибки, истечение, отзыв и browser-тесты.
- Иллюстрация mobile-меню 42 px; зона касания минимум 44 px. Лендинг — иллюстрация, не живой статус. Текст соответствует наличию релиза.
- Runtime QR содержит свежий временный challenge, а не постоянный токен.
- Проверяйте предупреждение HTTP, контраст, keyboard/D-pad, длинные имена, offline и ошибки. После уточнения эталонов перепроверяйте их в Pencil. Русские переносы проверяются на реальном runtime отдельно от англоязычных эталонов.

Проверка снимает блокировку доступа к Pencil, но не завершает сквозную приёмку V1.
