# Дизайн публичного сайта

[English](../../../../design/website/design.md)

Источник: `website.pen`, редактируемые desktop/mobile-фреймы. [Дизайн-система](../design-system.md).

## Desktop 1440×900
Навигация SendTV, возможности, сценарий, документация, GitHub. Hero: короткая подпись о локальной передаче; заголовок «Ссылка на телефоне. Страница на телевизоре.»; две кнопки; декоративный телефон/ТВ с линией связи без ложного живого статуса. Далее три шага и небольшие блоки возможностей, внизу точная информация о совместимости и приватности.

## Mobile 390×844
Одна колонка; меню, заголовок около 36 px; кнопки переносятся/располагаются вертикально; иллюстрация ТВ без горизонтальной прокрутки; доступные FAQ и документация.

## Компоненты и состояния
- CTA: начать, документация, GitHub. Адрес GitHub берётся из конфигурации репозитория.
- Матрица: Android TV поддерживается после выпуска V1; Tizen, webOS, mirroring — только правдивые плановые статусы.
- Анимация линий необязательна и учитывает reduced motion.
- Документация: левая панель от 240 px, поиск в шапке, читаемая центральная область до 760 px, правое оглавление на широком экране.
- English/Русский открывают тот же материал на другом языке; текст страницы и `lang` согласованы.

## Проверка
Скриншоты при 390, 768, 1440 px; порядок фокуса, контраст, отсутствие обрезки, соответствие `website/content.md`. Alt описывает hero как иллюстрацию.
