# HTTP-граница приёмника V1

[English](../../http-v1.md)

Приёмник слушает один явно выбранный частный IPv4-адрес и настраиваемый непривилегированный порт. Wildcard/публичные адреса отклоняются; loopback разрешён только в локальных тестах. Android-адаптер выбирает только Wi-Fi/Ethernet и останавливает/перепривязывает сервер при потере сети или смене адреса. Нет discovery, UPnP, произвольной загрузки URL и прокси.

Небольшой сервер реализует ограниченное подмножество HTTP/1.1: 4 worker, до 8 соединений в очереди, 8 KiB заголовков, 16 KiB тела, таймауты/deadline чтения, фиксированный Content-Length, один запрос на соединение. До маршрутизации отклоняются повторяющиеся заголовки, chunked-тела, абсолютные request target, path traversal, некорректный UTF-8, неподдерживаемые методы и неполные тела. Статика имеет точный allowlist. Это уменьшает зависимости и область аудита, но не обещает общую HTTP-совместимость или внешнюю сертификацию безопасности.

Host точно совпадает с выбранными адресом и портом — защита от DNS rebinding. Присутствующий Origin обязан точно совпадать с HTTP-origin приёмника; каждому изменяющему состояние запросу он обязателен. Cross-site fetch metadata запрещены. JSON строгий: нет повторных/неизвестных полей, требуемые поля — строки. Нет cookies и wildcard CORS. Ответы запрещают кеширование, встраивание во frame, утечку referrer и MIME sniffing; CSP допускает только self.

Open требует доверенный bearer. Операции закрыты для других устройств, ограничены 128 записями и пятью минутами, имеют ключ идемпотентности в пределах устройства. Другой URL с тем же ключом отклоняется. Перед выполнением очереди токен проверяется повторно, поэтому отзыв блокирует ещё не выполненный запуск. Статус отражает передачу Android, а не загрузку сайта. Хранится дайджест URL, а не адрес целиком. URL, токены, тела запросов и тексты исключений не логируются.

Контракт — [OpenAPI](../../../protocol/openapi.yaml). Реальные socket-тесты проверяют framing, лимиты, остановку и заголовки безопасности; API-тесты — разрешение/опрос, строгий JSON, неавторизованный доступ, Origin/Host, идемпотентность, изоляцию операций, отзыв и отсутствие браузера. Локальные тесты не доказывают совместимость мобильного браузера и физической LAN.

HTTP всё ещё раскрывает весь канал управления злоумышленнику в LAN. Используйте доверенную сеть и явно разрешайте новые устройства на ТВ. Аутентификация не является шифрованием транспорта.
