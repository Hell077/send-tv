# Английский и русский

[English](../../localization.md)

Приёмник, встроенный отправитель и статический сайт поддерживают английский и русский. Английские исходники сохранены; инженерные переводы повторяют пути в `docs/ru/`. Изменение требований обновляет оба текста. OpenAPI, идентификаторы кода, поля/error codes, команды и URL сохраняют исходное написание.

## ТВ

Настройки → Язык: язык системы, English, Русский. Выбор хранится локально, не меняет язык всего ТВ и не даёт доступ. Неподдерживаемое сохранённое значение возвращает системную конфигурацию; неподдерживаемый язык системы использует английские ресурсы. Пересоздание Activity применяет язык и возвращает на главный экран; несохранённые имя/порт не записываются выбором языка. Разрешение по-прежнему начинается с отказа. Сохранённые пользователем имена не переводятся.

Сетевой статус использует Android string resources, а не сохранённые английские фразы; асинхронные обновления тоже учитывают язык Activity. Полнота ключей и форматных аргументов проверяется.

## Отправитель

Изначально выбирается поддерживаемый язык браузера, иначе английский. Явный выбор сохраняется в `sendtv.language`, если доступен local storage, отдельно от токенов. Переключение обновляет подписи, статусы и ошибки без перезагрузки, отмены сопряжения, изменения цифр кода и ввода. Ошибка сохранения языка не мешает работе вкладки. Имена приёмников и введённые URL не переводятся.

Предупреждения HTTP, подтверждение ТВ, отсутствие браузера и фоновые ограничения переведены. Стабильные коды протокола остаются исходными и отображаются как локализованные сообщения.

## Сайт и документы

Русские маршруты `/ru/` имеют правильный HTML lang/метаданные, навигацию, руководства, приватность и changelog. English/Русский сохраняют текущий материал и project Pages base. Сайт не обращается к ТВ. Инженерные переводы имеют обратные ссылки; планы будущих версий остаются будущими работами.

## Проверка

Обычные Android/sender/site-команды плюс `python3 -m unittest discover -s scripts -p 'test_*.py'`. Guard проверяет Android keys/format, наличие инженерных переводов и локальные ссылки. Browser-регрессии: русский язык, override/reload, смена во время сопряжения, неизменный ввод/код, ошибки/fallback. Протокол от языка не меняется.

Проверка runtime 2026-11-05: эмулятор API 34 и Chromium/WebKit. Физические домашние ТВ/телефон во время проверки перевода недоступны; прежние английские проверки не сертифицируют русский layout на них. Скриншоты Home/settings и сайта записаны отдельно. Исходные редактируемые английские эталоны повторно открыты через Pencil MCP; расширение русского текста проверено в runtime. Точное совпадение русского дизайна не заявляется.
