# Скриншоты работающей системы

[English](../../../screenshots/README.md)

Сняты при проверке разработки 2026-11-04. Это реальные экраны, отдельно от эталонов Pencil.

- `tv-settings-api30.png`: физический MiTV-MOOQ1, сборка с минимумом API 30, настройки. Действующего QR и данных доступа нет.
- `tv-browser-api30.png`: установленный браузер физического ТВ с публичной example.com после передачи на `9a68c2f`. Диагностический префикс производителя до PNG-сигнатуры удалён из ADB-потока; пиксели не изменены.
- `site-mobile.png`, `site-desktop.png`: реальный статический сайт в Chromium при ширине 390/1440 CSS px. ТВ на лендинге — иллюстрация, не доказательство работы приёмника.

[Исходные изображения](../../../screenshots/) сняты до русского перевода и не доказывают универсальную совместимость сайтов или точность всех нативных экранов.

## Русский UI, 2026-11-05

- `tv-home-ru-api34.png`, `tv-settings-ru-api34.png`: реальный эмулятор API 34 после выбора пультом; приёмник остановлен, QR/токена нет. Действия настроек в одном ряду сохраняют нижние поля.
- `site-mobile-ru.png`: русский статический сайт в Chromium, 390 CSS px.
- `sender-unpaired-ru.png`: настоящий встроенный отправитель с локальным Kotlin test adapter, прямой визит без QR/токена. Английское имя фикстуры и уже имеющийся ввод сохраняются при смене языка.

Это проверка локализации runtime, не повторная сертификация физического ТВ. Изображения находятся в исходном `docs/screenshots/`.
