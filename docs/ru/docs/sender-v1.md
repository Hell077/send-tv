# Браузерный отправитель V1

[English](../../sender-v1.md)

Мобильный клиент — TypeScript-сайт с приёмника, а не отдельный нативный APK. Откройте его через QR на ТВ. Публичный GitHub Pages — только документация, он не подключается к приёмнику.

Отправитель сразу удаляет QR-фрагмент из адресной строки. Новый challenge в открытой вкладке обрабатывается через `hashchange`, как и первое открытие. Это важно при повторном сканировании с переиспользованием вкладки. Старый опрос не перезаписывает новое состояние; прежние запросы отменяются по возможности, иначе истекают на ТВ.

Токены изолированы по идентификатору приёмника и origin браузера. По умолчанию session storage; постоянный local storage — только после явного выбора «Запомнить». При ошибке хранилища текущий сеанс остаётся в памяти, но сохранение не подразумевается. Удаление в браузере стирает только локальную копию; другие отключаются отзывом на ТВ.

UI объявляет статусы/ошибки, использует текст не меньше 16 px и цели касания 44 px, единый адаптивный макет от 320 px, отмену, восстановление и повтор. Через HTTP буфер обмена может быть недоступен; обычная вставка браузера поддерживается. При неоднозначном сетевом сбое request ID переиспользуется, после определённого успеха/ошибки создаётся заново. Идемпотентность ограничена живым сеансом приёмника и пятью минутами; после перезапуска сначала проверьте ТВ.

Английский и русский выбираются по языку браузера, поддерживаемый явный выбор хранится отдельно в `sendtv.language`. Переключение не отменяет сопряжение, не меняет код, URL или имя устройства и не даёт авторизацию. Неподдерживаемое предпочтение возвращает английский.

Chromium и WebKit запускают реальный Kotlin HTTP/auth с тестовыми адаптерами решения ТВ и Android launch. Восемь сценариев на движок охватывают прямое открытие, повторный QR, разрешение/open/reload/forget при 320 px, ошибки URL/браузера/фона, отказ, доступность, русский, переключение и fallback. Это проверка движков, не физического iOS/Android; результаты ТВ и телефонов записываются отдельно. Трассы браузера и дампы запросов с секретами не сохраняются.
