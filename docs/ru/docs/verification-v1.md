[English](../../verification-v1.md)

Проверки разработки 2026-11-04, не сертификация релиза. Основные физические сценарии — `9a68c2f`; следующая сборка с минимумом API 30 успешно установлена и показала живой QR на том же ТВ. Проверка русского интерфейса фиксируется отдельно после локализации.

Контролируемый отказ повторён при неподвижном пульте после предыдущего разрешения с неясным источником ввода; доказательством отказа считается только повтор. Native-тест отдельно отправляет D-pad Center на исходно сфокусированный отказ.

Отсутствие браузера проверяется Android-тестами и фикстурами; установленный браузер с домашнего ТВ не удалялся. WebKit не сертифицирует физический Safari. iOS/Windows, LAN без Интернета, гостевая изоляция и 4K runtime не проверены. Настройки домашней сети не менялись. Headless-эмулятор проигнорировал `3840×2160` wm override и остался 1920×1080; density восстановлена, 4K не заявляется.

HTTP раскрывает ссылки и данные доступа наблюдателю. Подтверждение ТВ не шифрует транспорт. Успешный intent не доказывает общую загрузку и совместимость сайтов.

Локальная финальная проверка до локализации: 37 JVM/resource/socket, 12 sender browser, 10 site browser для local-root и project-base, три site unit/build; Kotlin, lint (0 ошибок, 13 неподавленных предупреждений), TS, ESLint, Prettier, OpenAPI, lockfile и guardrails — успешно.
