# Протокол работы агента

[English](../../../governance/agent-workflow.md)

Для каждой задачи:
1. Определите текущую версию плана и точный критерий приёмки.
2. Прочитайте архитектурные ограничения и визуальные спецификации затронутых функций.
3. Выделите минимальный проверяемый сквозной срез; для критичного поведения сначала опишите тесты.
4. Реализуйте, отформатируйте, протестируйте, документируйте и осмотрите UI на телефоне, настольном экране и ТВ.
5. Делайте логические коммиты, а не один огромный на весь этап.
6. Сообщите выполненные критерии, реально запущенные команды, результаты, ограничения и SHA коммитов.

Не пропускайте упавшие тесты, не выдумывайте согласование скриншотов, не удаляйте ограничения ради CI, не выполняйте незапрошенные сетевые обращения и не добавляйте телеметрию.

## Завершение задачи
- [ ] Требования выполнены
- [ ] Граница безопасности сохранена
- [ ] Есть модульные и интеграционные тесты
- [ ] Пользовательские ошибки обработаны
- [ ] Документация / OpenAPI обновлены
- [ ] Дизайн проверен по `.pen` и спецификации
- [ ] Коммит соответствует `git.md`
