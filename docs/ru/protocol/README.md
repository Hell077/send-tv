# Примечания к API

[English](../../../protocol/README.md)

`openapi.yaml` описывает info, запрос/опрос/отмену сопряжения, open и операции. Негативные тесты ядра устанавливают истечение и одноразовость challenge, локальное разрешение на ТВ, отдельную авторизацию опроса и сохранение хешей до интеграции транспорта. QR несёт nonce во фрагменте URL; отправитель удаляет его перед запросами. Это никогда не постоянные данные доступа.

Challenge, решения, список устройств и отзыв — локальные методы ТВ, не HTTP-endpoint. Данные опроса истекают вместе с запросом через 60 секунд. Отправитель использует same-origin JSON, без cookies и wildcard CORS. См. [сопряжение](../docs/pairing-v1.md) и [API](../architecture/api.md).

Каноническая машиночитаемая схема остаётся в [исходном OpenAPI](../../../protocol/openapi.yaml); имена полей, пути и коды ошибок не переводятся.
