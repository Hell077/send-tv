# MVP V1: сопряжение и открытие URL

[English](../../../../roadmap/mvp/version-1.md)

## Цель
Камерой телефона отсканировать QR на Android TV, разрешить первое устройство на ТВ, вставить URL и надёжно передать его установленному ТВ-браузеру.

## Объём и порядок
1. Нативная оболочка Compose или Views, фокусируемый интерфейс с большого расстояния, главный экран и настройки.
2. Встроенный HTTP со статикой приложения; настраиваемый порт, явный жизненный цикл, только разрешённые интерфейсы.
3. Автомат сопряжения, QR, разрешение ТВ, сохранение хешей, отзыв, лимиты.
4. `GET /v1/info`, сопряжение, `POST /v1/open`, статусы. Текущий `protocol/openapi.yaml`.
5. Строгий URL-валидатор и `ACTION_VIEW`; отсутствие обработчика; без скрытого повышения привилегий.
6. Адаптивный отправитель: ожидание, подключение, разрешение ТВ, подключено, отправка, запуск, некорректный URL, недоступность, отсутствие браузера.
7. Ошибки, доступность, проверка приватности/безопасности, offline LAN.
8. Установка APK, сеть, разрешения, браузеры, неполадки, скриншоты.

## Приёмка
- [x] APK устанавливается на выбранной после тестирования минимальной версии Android; версия документирована.
- [x] D-pad-навигация; QR с временным challenge URL.
- [x] Новый отправитель получает доступ только после разрешения ТВ; истёкшие/повторные challenge отклоняются.
- [x] Корректный HTTPS URL открывается совместимым обработчиком.
- [x] Неподдерживаемая схема, некорректный URL и отсутствие браузера имеют понятные ошибки.
- [x] Отзыв сразу отключает последующие команды.
- [x] Негативные auth/pairing-тесты проходят; полные URL-секреты не логируются.
- [ ] Отправитель работает в мобильных Safari/Chrome и актуальных desktop-браузерах, где разрешён LAN fetch.
- [ ] Публичный GitHub Pages с лендингом и началом работы, без подключения к живому ТВ.

Доказательства: [протокол V1](../../docs/verification-v1.md). Отсутствие браузера проверено контролируемыми Android/browser-тестами. Физические iOS/Windows, offline/guest-isolation ещё не проверены. Отметки не означают прохождение полной матрицы V1.

## Матрица
Эмулятор и минимум один реальный ТВ; Chrome Android, Safari iOS, Chrome macOS/Windows; общий Wi-Fi, без Интернета, телефон в изолированной гостевой сети, первое и повторное сопряжение, отзыв, отсутствие браузера, URL с данными входа, истёкший QR, перезапуск процесса. Невыполненные физические проверки отмечайте явно.

## Не реализовывать
Файлы, Google Cast, трансляцию экрана, другие ОС ТВ, инъекцию мыши, обязательный TLS без модели доверия, discovery из обычного браузера.
