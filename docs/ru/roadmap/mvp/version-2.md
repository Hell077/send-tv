# MVP V2: поиск, несколько устройств, CLI

[English](../../../../roadmap/mvp/version-2.md)

## Зависимости
V1 принята после проверок безопасности и сквозных тестов. Возможности API стабильны.

## Работы
1. Нативная DNS-SD-реклама Android TV `_sendtv._tcp` со стабильным instance ID и очищенными TXT-метаданными.
2. Go CLI `sendtv discover`, `sendtv pair`, `sendtv devices`, `sendtv open URL [--device id]`, `sendtv status`; без OS shell expansion URL.
3. Выбор нескольких доверенных приёмников: понятные имена, время последнего появления.
4. Reconnect/re-pair браузера, предсказуемый QR прямого адреса, ручной IP в нативном CLI.
5. Доверенные ключи/токены нативного отправителя в системном keychain; не в истории CLI и логах.
6. Exit codes, машинный `--json`, отмена, таймауты, стабильные ошибки.
7. Pages: установка CLI, команды, проблемы discovery, возможности.

## Приёмка
- [ ] Несколько объявлений находятся в обычной домашней подсети.
- [ ] CLI выбирает по ID и отправляет правильному ТВ, в том числе при одинаковых именах.
- [ ] QR/прямой адрес работают при блокировке multicast и разрешённом unicast LAN.
- [ ] Discovery не даёт авторизации.
- [ ] CLI не хранит plaintext-токен без явного документированного opt-in fallback.
- [ ] Тесты parsing, повторных ID, старого IP, таймаутов, auth expiry, конфликтов имён.

## Не обещается
Межподсетевой поиск без настройки, браузерный mDNS, произвольное открытие URL на ТВ без приёмника.
