# V3: файлы и удалённое управление после первоначального MVP

[English](../../../../roadmap/mvp/version-3.md)

## Функции
- Изображения и PDF с явным принятием, безопасным MIME, пределом размера и ограниченным хранением на ТВ.
- Галерея с удалением/истечением, защищёнными временными URL, запретом ZIP-бомб и некорректных payload.
- Медиа: согласование кодеков/контейнеров, direct play где доступно, без автоматической загрузки в облако.
- Управление только собственным WebView приёмника: назад, вперёд, обновить, прокрутить; без произвольного ввода в сторонние приложения.
- WebSocket-события с проверкой origin и защитой от replay.

## Приёмка
Изображения и небольшие PDF отображаются без стороннего облака; нет path traversal; квота enforced; отмена освобождает ресурсы; удалённые действия требуют аутентифицированного доверия; документация описывает пределы кодеков.
