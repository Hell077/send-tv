The active implementation milestone is **V1: pair and open a URL through a receiver-hosted web sender**. The Go CLI, native discovery and multi-device selection are planned for V2, after V1 passes acceptance.

No CLI installation command or download is available. Use the [V1 development flow](../getting-started/) and do not treat roadmap entries as shipped features.
