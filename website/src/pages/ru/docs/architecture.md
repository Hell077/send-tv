<h2 id="the-path-of-a-link">Путь ссылки</h2>

Камера телефона → интерфейс с приёмника → локальный HTTP JSON → авторизация → Android `ACTION_VIEW` → установленный ТВ-браузер или обработчик.

Приложение на Kotlin раздаёт встроенный TypeScript-интерфейс и версионированный протокол. Оно не загружает целевые URL, не работает как прокси, не исполняет команды оболочки и не открывает произвольные ресурсы localhost/LAN. Нет облачного посредника, аккаунта, обязательного внешнего сервиса, отслеживания или удалённой телеметрии.

Этот публичный сайт — статическая сборка GitHub Pages. Он не является отправителем и не пытается подключиться к ТВ. Раздача интерфейса с приёмника устраняет зависимость от HTTPS-сайта, обращающегося к частному HTTP-сервису, но **не шифрует** локальный трафик.

<h2 id="authorization">Авторизация</h2>

ТВ создаёт случайный 256-битный одноразовый код с коротким сроком действия. Он помещён во фрагмент URL в QR-коде; отправитель удаляет его из адресной строки перед запросами протокола. Отдельные случайные данные доступа защищают опрос ожидающего запроса: знания request ID недостаточно для получения токена.

Долгосрочный токен выдаётся только после локального решения на ТВ. Приёмник хранит SHA-256-хеши и исключает данные из резервного копирования и переноса. Отзыв блокирует последующие команды, включая поставленные в очередь, но ещё не переданные Android. Публичных endpoint для разрешения или отзыва нет.

HTTP проверяет точные Host и Origin, строгий JSON, ограничения запросов и соединений, частоту запросов и идемпотентность в пределах устройства. Эти меры не заменяют аутентифицированное шифрование транспорта.

<h2 id="known-limitations">Известные ограничения</h2>

- **Локальный HTTP виден злоумышленнику в LAN.** Ссылки и данные доступа могут быть перехвачены. Не отправляйте конфиденциальные ссылки через недоверенный Wi-Fi.
- На Android TV нужно установить приёмник. Произвольными неизменёнными ТВ управлять нельзя.
- Ограничения Android на фоновый запуск и жизненный цикл процесса сохраняются. Для команд держите приёмник на переднем плане или возвращайтесь в него.
- Успешная передача не доказывает загрузку страницы. Влияют браузер, вход в аккаунт, cookies, DRM и пульт.
- Нужна доступность по IPv4 LAN. Меж-VLAN, IPv6-only, обнаружение устройств, кастинг и трансляция экрана не гарантируются.

Локальный TLS с моделью доверия к устройству — будущая работа. V1 нельзя представлять как зашифрованный канал управления.
