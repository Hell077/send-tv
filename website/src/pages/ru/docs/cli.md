title: CLI планируется в V2
description: CLI SendTV и нативный поиск устройств запланированы после приёмки V1.
---

Активный этап — **V1: сопряжение и открытие URL через веб-интерфейс с приёмника**. Go CLI, нативный поиск устройств и выбор нескольких устройств планируются в V2 после прохождения приёмки V1.

Команды установки и загрузки CLI нет. Используйте [сценарий разработки V1](../getting-started/) и не считайте пункты плана выпущенными функциями.
