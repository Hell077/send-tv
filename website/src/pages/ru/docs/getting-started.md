<h2 id="before-you-start">Перед началом</h2>

**V1 ещё не выпущена и проходит проверку на устройствах.** Проверенного публичного APK нет. Текущая сборка предназначена для разработки и тестирования, а не для конечных пользователей.

Нужны Android / Google TV для разработки, совместимый установленный браузер или обработчик HTTP(S)-ссылок и телефон или компьютер в той же доверенной сети Wi-Fi/Ethernet. Samsung Tizen и LG webOS не поддерживаются. Изоляция клиентов и межсетевые экраны VLAN могут препятствовать подключению.

Начальная поддерживаемая версия — **Android 11/API 30**, выбранная после проверки на физическом MiTV-MOOQ1. API 34 проверяется в эмуляторе Android TV. Старые версии и другие модели не входят в первоначальную проверенную совместимость. Сборка с минимумом API 30 успешно переустановлена на этом ТВ; это не подтверждает совместимость всех моделей API 30+.

<h2 id="install">Установка</h2>

Для разработчиков: JDK 21, Node 24, Android SDK platform 36 и build-tools 36.0.0. Клонируйте репозиторий, установите зафиксированные зависимости и соберите APK:

```sh
npm ci --ignore-scripts --no-audit --no-fund
./gradlew :tv:assembleDebug
```

APK: `tv/build/outputs/apk/debug/tv-debug.apk`. Он подписан локальным ключом разработки. Установите его на разрешённое вами тестовое устройство:

```sh
adb install -r tv/build/outputs/apk/debug/tv-debug.apk
adb shell am start -n org.sendtv.receiver/.ReceiverActivity
```

ADB нужен здесь только для установки и исследования тестовой сборки. Обычное сопряжение и отправка не используют ADB, команды оболочки или повышенные разрешения Android.

<h2 id="pair">Сопряжение</h2>

1. Откройте SendTV на телевизоре. Выберите **Запустить приёмник** и прочитайте предупреждение о незашифрованном HTTP. Оставьте SendTV на переднем плане.
2. Отсканируйте QR-код камерой телефона. Интерфейс отправки загружается с ТВ, а не с публичного сайта. Код действует 60 секунд и принимается один раз.
3. Введите имя устройства. **Запомнить этот браузер** выбирайте только для доверенного устройства и сети. Иначе данные доступа хранятся в сеансе вкладки.
4. Нажмите **Запросить разрешение на ТВ**. Сравните код на обоих экранах и явно выберите **Разрешить** на ТВ. По умолчанию фокус на **Отклонить**.

В настройках ТВ можно выбрать язык системы, English или Русский. Отправитель сначала учитывает язык браузера; его переключатель позволяет выбрать английский или русский. Выбор языка не заменяет подтверждение сопряжения.

HTTP не шифрует коды, bearer-токены и ссылки. Злоумышленник в локальной сети может их перехватить. Используйте доверенную сеть и не отправляйте конфиденциальные ссылки через общий или недоверенный Wi-Fi.

<h2 id="send">Отправка</h2>

Вставьте HTTP(S)-адрес в **Адрес сайта** и нажмите **Открыть на ТВ**. Встроенные данные входа, небезопасные схемы, некорректные адреса и ссылки длиннее 4096 символов отклоняются.

«Android принял ссылку» означает успешную передачу `ACTION_VIEW`, а не загрузку страницы. Вход в аккаунт, Widevine, cookies, обработчик и ввод с пульта могут влиять на результат.

Android ограничивает запуск из фоновых приложений. Вернитесь в SendTV на телевизоре перед следующей отправкой, если интерфейс об этом просит. Сервер живёт в процессе приложения: Android может завершить его в фоне. После перезапуска откройте SendTV и запустите приёмник; хеши доверенных токенов сохраняются, ожидающие запросы — нет.

Для отзыва доступа откройте **Устройства** на ТВ и отзовите доступ одного или всех устройств. **Забыть этот браузер** удаляет только локальную копию и не отзывает скопированные данные доступа.
